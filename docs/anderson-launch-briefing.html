4 · What Needs Redirects — and Exactly How

There is exactly one redirect to create: the custom subdomain leads.bentondrones.com pointing at the live app. This is what turns the long onrender.com address into a Benton Drones branded address.

The one rule that protects email: when creating DNS records, do not touch, edit, or delete any existing MX, SPF (TXT), DKIM, or DMARC records. Those keep @bentondrones.com email working. We are only adding one new CNAME record — nothing else changes.

1 In the Render dashboard (~10 min)

  1. Log into dashboard.render.com → open the benton-drones-lead-ingest service.
  2. Left sidebar → Settings → Custom Domains → Add Custom Domain.
  3. Enter exactly: leads.bentondrones.com and save.
  4. Render will show you a target address like benton-drones-lead-ingest.onrender.com and begin waiting for DNS. Copy that target — you need it in step 2.

2 At the DNS provider (~10 min)

First, find out who controls DNS: log into Namecheap → Domain List → bentondrones.com → check the nameservers. They'll either say "Namecheap BasicDNS / default" or "Cloudflare nameservers". Wherever the nameservers point is where you add the record.

  1. Open the DNS management page (Namecheap: Domain List → Manage → Advanced DNS).
  2. Add one new record: 
    Type:   CNAME
Host:   leads
Value:  benton-drones-lead-ingest.onrender.com
TTL:    Automatic (or 5 minutes)
  3. Save. Do not edit or remove any other record. (If a screen asks about "URL Redirect Record" types — that's the wrong tool; use CNAME.)

3 Back in Render: verify + certificate

  1. Back on the Custom Domains page in Render, click Verify. DNS takes anywhere from 2 minutes to 1 hour to be visible.
  2. Once verified, Render issues a free HTTPS certificate automatically. Green lock = done.
  3. Smoke test: open https://leads.bentondrones.com/healthz — it must say "status": "ok". Then submit one test signup at https://leads.bentondrones.com/signup and see it in the admin dashboard.
After the cutover: bentondrones.com (the Shopify store) is untouched, leads.bentondrones.com serves this system, and shop pages simply link the "Get a Quote / Sign Up" button to https://leads.bentondrones.com/signup. No redirects on the old site are needed at all — just new links/buttons pointing to the new address.

6 · The End-to-End Picture of What Is Built

What happens, in order, for every real customer:

  1. Customer clicks the Sign Up button (on the landing page today; on the Shopify site after section 4) and fills out /signup: name, contact, address, service details, waiver, typed e-signature.
  2. Security layer (in microseconds): honeypot rejects bots silently; rate limiter enforces 5 signups/min/IP; CSRF tokens block forged submissions; over-size bodies rejected.
  3. Validation: required fields, email/phone formats. Junk never reaches the database.
  4. One atomic database write stores: the lead, the exact waiver text + version, consent timestamps, IP, browser, and the signature.
  5. Geocoding: the address becomes GPS coordinates (Census → global fallback, results cached so repeats are free). If geocoding ever fails, the signup still succeeds — the lead is marked for later re-try. Pins can never block a lead.
  6. Same transaction queues the customer confirmation email + Anderson's internal alert, and a JIRA ticket request. Each queue retries automatically with backoff and dead-letters (loudly, in admin) after 5 failures instead of vanishing.
  7. Customer sees a branded confirmation page. Anderson sees the lead instantly on the admin dashboard map, plus email + JIRA (once credentialed).
  8. Planning: Anderson opens the dashboard, filters leads, and downloads CSV (spreadsheets) or KML (opens straight in Google Earth) — replacing the manual Sheets + Google Earth plotting entirely.
  9. Care & feeding: /healthz proves app+database are alive; the backup-verify script can certify any database copy read-only; the recovery playbook documents restore step-by-step.

Ordered checklist for right now while you have all the logins at hand. Each takes minutes; do them top-to-bottom:
